# Astroman Business Hub

Consolidates **Astroman-daily**, **Lisa-Daily**, **Astroman-Marketing-Agent**, and **New-Product-Ideas**.

## Jobs

| Job | Schedule (Tbilisi) |
|-----|---------------------|
| `astroman_daily` | Daily 09:00 — Georgian morning routine |
| `lisa_morning` | Daily 10:00 — CEO strategic brief |
| `lisa_evening` | Daily 21:00 — CEO evening analysis |
| `marketing` | Daily 12:00 & 20:00 — AI marketing plans |
| `product_scout` | Daily 12:00 & 18:00 — Alibaba/DHgate product digest |

## Secrets

- `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID`
- `OPENAI_API_KEY`
- `ANTHROPIC_API_KEY` (Lisa CEO mode)

## Manual run

Actions → **Astroman Business Hub** → Run workflow.
